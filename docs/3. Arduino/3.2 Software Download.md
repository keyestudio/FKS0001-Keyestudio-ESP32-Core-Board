# 3.2 Descarga de Software

Cuando recibimos la placa de control, primero necesitamos descargar Arduino IDE y el driver.

Puedes descargar Arduino IDE desde la página oficial: <https://www.arduino.cc/en/software>.

Existen varias versiones de Arduino, solo descarga la versión adecuada para tu sistema. Tomaremos como ejemplo el sistema WINDOWS para mostrarte cómo descargar e instalar.

![](media/A1.gif)

Solo necesitas hacer clic en JUST DOWNLOAD, luego hacer clic en el archivo descargado para instalarlo.

Y cuando el archivo ZIP esté descargado, puedes descomprimirlo directamente y ejecutarlo.

![](media/A2.gif)

### Instalación y configuración del entorno ESP32

1. Haz clic en "Archivo" y selecciona "Preferencias".
![](media/A3.png)

2. Haz clic en "![](media/A4.png)", copia y pega el enlace del paquete de la placa de desarrollo ESP32: `https://espressif.github.io/arduino-esp32/package_esp32_index.json` en el cuadro de texto, luego haz clic en "**OK**".
![](media/A5.png)

3. Haz clic en "OK" nuevamente.
![](media/A6.png)

4. Haz clic en el pequeño ícono de la placa de desarrollo a la izquierda para abrir las opciones de placas.
![](media/A7.png)

5. En el cuadro de búsqueda de placas, busca "ESP32", selecciona la versión "2.0.6" y haz clic en instalar.
![](media/A8.png)

**Nota: Puedes ver el progreso de la instalación de la placa en la esquina inferior derecha. Por favor espera unos minutos hasta que la instalación termine. Durante la instalación, mantén tu red estable. Si la instalación falla, repite los pasos anteriores y reinstala la placa de desarrollo.**

![](media/A9.png)

### Añadir Biblioteca

Las bibliotecas son una colección de código que facilita la conexión a un sensor, pantalla, módulo, etc.

Existen cientos de bibliotecas adicionales disponibles en Internet para descargar.

Te mostraremos la forma más sencilla para añadir bibliotecas.

Localiza la carpeta "Libraries" dentro del material descargado al inicio, y anota su ruta en tu computadora; esto es de suma importancia.

![](media/A10.png)

Este método solo puede importar un archivo de biblioteca a la vez, por lo que necesitamos repetir el proceso para importar todos los archivos de biblioteca. (Aquí demostramos la importación solo del archivo AsyncTCP.zip; es recomendable importar todas las bibliotecas en esta etapa para evitar olvidos en lecciones posteriores.)

![](media/A11.gif)

### Verificación del Driver

Aquí necesitamos verificar si los drivers están instalados en la computadora.

1. Sin conectar la placa de desarrollo ESP32 a la computadora, abre el puerto como se muestra a continuación. Observa las opciones de puerto disponibles; como se ilustra, solo está presente COM1.
![](media/A12.png)

2. Cierra la ruta abierta previamente y regresa a la interfaz de programación. Conecta la placa de desarrollo ESP32 a la computadora, luego vuelve a abrir el puerto para verificar nuevas opciones de puerto. Como se muestra a continuación, ahora aparece COM6.
![](media/A13.png)

3. En este punto, COM6 es el puerto para la placa de desarrollo ESP32, confirmando que los drivers se han instalado automáticamente.

4. Si no aparecen nuevos puertos después de conectar la placa, por favor cambia el cable de datos y prueba con otro puerto USB en la computadora. Si el problema persiste, consulta la sección "**Instalación del driver**" para instalar el driver.
![](media/A14.png)

### Verificación de Configuración del Software

En este punto, hemos completado todas las configuraciones de software. Ahora conecta la placa de desarrollo ESP32 a la computadora y verifica que el entorno funcione correctamente.

![](media/A15.gif)

Nota: Podemos simplemente subir el código por defecto directamente. La subida exitosa confirma que nuestra configuración del entorno está funcionando correctamente, como se muestra en el gif animado.
