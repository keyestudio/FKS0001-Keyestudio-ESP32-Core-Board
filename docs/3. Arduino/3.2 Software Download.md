# 3.2 Software-Download

Wenn wir das Steuerboard erhalten, müssen wir zunächst die Arduino IDE und den Treiber herunterladen.

Die Arduino IDE können Sie von der offiziellen Webseite herunterladen: <https://www.arduino.cc/en/software>.

Es gibt verschiedene Versionen für Arduino, laden Sie einfach eine passende Version für Ihr System herunter. Wir verwenden das WINDOWS-System als Beispiel, um Ihnen zu zeigen, wie man herunterlädt und installiert.

![](media/A1.gif)

Sie müssen nur auf JUST DOWNLOAD klicken und dann die heruntergeladene Datei zur Installation öffnen.

Wenn die ZIP-Datei heruntergeladen wurde, können Sie sie direkt entpacken und starten.

![](media/A2.gif)

### Installation und Konfiguration der ESP32-Umgebung

1. Klicken Sie auf „Datei“ und wählen Sie „Voreinstellungen“.
![](media/A3.png)

2. Klicken Sie auf "![](media/A4.png)", kopieren Sie den ESP32-Entwicklungsboard-Link: `https://espressif.github.io/arduino-esp32/package_esp32_index.json` in das Textfeld und klicken Sie dann auf "**OK**".
![](media/A5.png)

3. Klicken Sie erneut auf „OK“.
![](media/A6.png)

4. Klicken Sie auf das kleine Entwicklungsboard-Symbol links, um die Entwicklungsboard-Optionen zu öffnen.
![](media/A7.png)

5. Suchen Sie im Suchfeld für Entwicklungsboards nach „ESP32“, wählen Sie die Version „2.0.6“ aus und klicken Sie auf installieren.
![](media/A8.png)

**Hinweis: Den Installationsfortschritt des Entwicklungsboards sehen Sie unten rechts. Bitte warten Sie einige Minuten, bis die Installation abgeschlossen ist. Halten Sie während der Installation Ihre Netzwerkverbindung stabil. Sollte die Installation fehlschlagen, wiederholen Sie die obigen Schritte und installieren Sie das Entwicklungsboard erneut.**

![](media/A9.png)

### Bibliothek hinzufügen

Bibliotheken sind Sammlungen von Code, die es Ihnen erleichtern, eine Verbindung zu einem Sensor, Display, Modul usw. herzustellen.

Im Internet sind Hunderte zusätzlicher Bibliotheken zum Download verfügbar.

Wir zeigen Ihnen die einfachste Methode, um Bibliotheken hinzuzufügen.

Suchen Sie den Ordner „Libraries“ in den zu Beginn heruntergeladenen Materialien und merken Sie sich den Pfad auf Ihrem Computer; dies ist von größter Bedeutung.

![](media/A10.png)

Diese Methode kann jeweils nur eine Bibliotheksdatei importieren, daher müssen wir den Vorgang wiederholen, um alle Bibliotheksdateien zu importieren. (Hier demonstrieren wir nur den Import der AsyncTCP.zip-Bibliothek; es ist ratsam, alle Bibliotheken zu diesem Zeitpunkt zu importieren, um spätere Vergesslichkeit zu vermeiden.)

![](media/A11.gif)

### Treiberprüfung

Hier müssen wir überprüfen, ob die Treiber auf dem Computer installiert sind.

1. Öffnen Sie ohne angeschlossenes ESP32-Entwicklungsboard den Port wie unten gezeigt. Beachten Sie die verfügbaren Portoptionen; wie dargestellt, ist nur COM1 vorhanden.
![](media/A12.png)

2. Schließen Sie den zuvor geöffneten Pfad und kehren Sie zur Programmieroberfläche zurück. Verbinden Sie das ESP32-Entwicklungsboard mit dem Computer und öffnen Sie den Port erneut, um nach neuen Portoptionen zu suchen. Wie unten gezeigt, erscheint nun COM6.
![](media/A13.png)

3. COM6 ist nun der Port für das ESP32-Entwicklungsboard, was bestätigt, dass die Treiber automatisch installiert wurden.

4. Wenn nach dem Anschluss an das Board keine neuen Ports erscheinen, tauschen Sie bitte das Datenkabel aus und versuchen Sie einen anderen USB-Port am Computer. Sollte das Problem weiterhin bestehen, lesen Sie den Abschnitt "**Treiberinstallation**" zur Installation des Treibers.
![](media/A14.png)

### Software-Konfigurationsprüfung

An diesem Punkt haben wir alle Softwarekonfigurationen abgeschlossen. Verbinden Sie nun das ESP32-Entwicklungsboard mit dem Computer und überprüfen Sie, ob die Umgebung korrekt funktioniert.

![](media/A15.gif)

Hinweis: Wir können einfach den Standardcode direkt hochladen. Ein erfolgreicher Upload bestätigt, dass unsere Umgebungskonfiguration korrekt funktioniert, wie im animierten GIF gezeigt.
