# 5. Treiberinstallation

## 5.1 Windows-System

**Treiberüberprüfung**

1. Verbinden Sie das Motherboard mit dem Computer.

![](media/A1.jpg)

2. Öffnen Sie den Geräte-Manager. Wenn die Meldung **"Silicon Labs CP210x USB to UART Bridge (COMx)"** erscheint, ist der Treiber bereits installiert. Bitte überspringen Sie dann den Abschnitt **"Treiberinstallation"**.

![](media/A2.gif)

**Manuelle Treiberinstallation**

1. Treiber herunterladen

- Windows-System: [Windows-System-Treiber](./Windows.7z)

2. Verbinden Sie das Motherboard mit dem Computer, öffnen Sie den Geräte-Manager. Wenn vor dem Treiber ein gelbes Ausrufezeichen erscheint, ist der Treiber nicht installiert. Bitte laden Sie den Treiber herunter und installieren Sie ihn manuell.

![](media/A3.gif)

## 5.2 MAC-System

**1. Treiberüberprüfung**

Verbinden Sie das Entwicklungsboard mit dem Computer. Wählen Sie im Menü [Tools] ---> [Port] den Port des Entwicklungsboards aus (Hinweis: Wenn Sie den Port des Entwicklungsboards nicht sicher identifizieren können, verbinden Sie das Motherboard und machen Sie Fotos aller Ports. Trennen Sie dann das Entwicklungsboard, machen Sie erneut Fotos aller Ports und vergleichen Sie die Bilder, um den verschwundenen Port zu finden. Der verschwundene Port ist der Port des Boards. Wählen Sie diesen Port anschließend aus.) Wenn der Port nicht erkannt wird, wechseln Sie den USB-Anschluss am Computer oder das Kabel und versuchen Sie es erneut. Falls es weiterhin nicht funktioniert, folgen Sie den nächsten Schritten zur Treiberinstallation.

![](media/A4.png)

**2. Manuelle Treiberinstallation**

1. Treiber herunterladen

​       Mac-System: [Mac-System-Treiber](./Mac.7z)

2. Doppelklicken Sie auf das heruntergeladene Treiber-ZIP-Paket, um es zu entpacken.

![](media/A5.png)

![](media/A6.png)

![](media/A7.png)

3. Klicken Sie anschließend auf **"Next"** und installieren Sie weiter, bis die Installation abgeschlossen ist.

![](media/A8.png)

An diesem Punkt sollte der Port durch erneutes Einstecken des Boards erkannt werden.

4. Öffnen Sie dann die Arduino IDE, klicken Sie auf „Tools“, wählen Sie das Board Arduino Uno und den erkannten Entwicklungsboard-Port aus.

![](media/A9.png)

5. Klicken Sie ![image-20250417085312966](media/A10.png), um den Code hochzuladen. Es erscheint die Meldung „Done uploading“.

![](media/A11.png)
