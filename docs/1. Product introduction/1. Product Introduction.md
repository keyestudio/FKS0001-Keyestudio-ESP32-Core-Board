# 1. Introducción al Producto

![](media/A1.png)

## 1.1 Descripción

Este kit de aprendizaje es una herramienta programable especializada para niños mayores de 6 años, que cuenta con 15 módulos y sensores como LEDs, botones, un LCD, un fotosensor, un sensor de sonido, un receptor IR, un sensor de temperatura y humedad, así como más de 30 proyectos interesantes.

Se proporciona el lenguaje Arduino C, que permite cultivar el pensamiento de programación.

## 1.2 Características

1. Cableado fácil: El cableado de VCC y GND está oculto.

2. Múltiples funciones: Se pueden usar placas de desarrollo Nano o ESP32 como placa de control y se integran 15 sensores. Cuando se conecta la fuente de alimentación externa, el interruptor DIP puede usarse para controlar el voltaje de VCC a 3.3V o 5V.

3. Estructura simple: Usa pilares de cobre de doble paso de 6mm para conectar la placa acrílica.

4. Alta expansibilidad: Se proporcionan pines VCC y GND.

5. Aprendizaje de programación: Está disponible el lenguaje Arduino C.

## 1.3 Parámetros

- **Voltaje de trabajo:** 5V o 3.3V  
- **Alimentación DC:** 7-12V  

- **Alimentación USB:** 5V  
- **Corriente de trabajo:** ≥35mA  

- **Temperatura de trabajo:** –10°C ~ +65°C

## 1.5 Placa de Control ESP32

![](media/A21.png)

**Introducción**

La placa Keyestudio ESP32 Core es una placa de desarrollo Mini basada en el módulo ESP-WROOM-32. La placa ha sacado la mayoría de los puertos I/O a conectores de pines con paso de 2.54mm. Esto proporciona una forma fácil de conectar periféricos según tus propias necesidades.

Al desarrollar y depurar con la placa de desarrollo, los conectores estándar en ambos lados pueden hacer que tu operación sea más simple y práctica.

El módulo ESP-WROOM-32 es la solución integrada líder en la industria para WiFi + Bluetooth con menos de 10 componentes externos. Integra conmutadores de antena, balun RF, amplificadores de potencia, amplificadores de bajo ruido, filtros y módulos de gestión de energía. Al mismo tiempo, también integra la tecnología de bajo consumo de 40nm de TSMC, rendimiento de potencia y rendimiento RF, haciéndolo seguro, confiable y fácil de expandir a una variedad de aplicaciones.

**Especificaciones**

- Microcontrolador: Módulo ESP-WROOM-32  
- Chip USB-serial: CP2102-GMR  
- Voltaje de trabajo: DC 5V  
- Corriente de trabajo: 80mA  
- Suministro de corriente: 500mA  
- Rango de temperatura de trabajo: -40°C ~ +85°C  
- Modo WiFi: Station/SoftAP/SoftAP+Station/P2P  
- Protocolo WiFi: 802.11 b/g/n/e/i (802.11n, velocidad hasta 150 Mbps)  
- Rango de frecuencia WiFi: 2.4 GHz ~ 2.5 GHz  
- Protocolo Bluetooth: conforme a Bluetooth v4.2 BR/EDR y estándar BLE  
- Dimensiones: 55*26*13mm  
- Peso: 9.3g  

**Distribución de pines**

![](media/A22.png)

ESP32 tiene menos pines que los procesadores comúnmente usados, pero no tiene problemas para reutilizar múltiples funciones en los pines.

**Advertencia**: El nivel de voltaje de los pines del ESP32 es 3.3V. Si deseas conectar el ESP32 a otro dispositivo con un voltaje de operación de 5V, debes usar un convertidor de nivel para adaptar el nivel de voltaje.

- **Pines de alimentación:** El módulo tiene dos pines de alimentación +5V y 3.3V. Puedes usar estos dos pines para alimentar otros dispositivos y módulos.

![](media/A23.png)

- **Pines GND:** El módulo tiene tres pines de tierra.  
- **Pin Enable (EN):** Este pin se usa para habilitar y deshabilitar módulos. El pin habilita el módulo en nivel alto y lo deshabilita en nivel bajo.  
- **Pines de Entrada/Salida (GPIO):** Puedes usar 32 pines GPIO para comunicarte con LEDs, interruptores y otros dispositivos de entrada/salida. También puedes activar internamente resistencias pull-up o pull-down en estos pines.  
- **Nota:** Aunque los pines GPIO6 a GPIO11 (SCK/CLK, SDO/SD0, SDI/SD1, SHD/SD2, SWP/SD3 y SCS/CMD) se usan para comunicación SPI del módulo interno, no se recomiendan para uso general.  

- **ADC:** Puedes usar los 16 pines ADC en este módulo para convertir voltajes analógicos (salida de algunos sensores) en voltajes digitales. Algunos de estos convertidores están conectados a amplificadores internos capaces de medir voltajes pequeños con alta precisión.  
- **DAC:** El módulo ESP32 tiene dos convertidores D/A con precisión de 8 bits.  

- **Touch pad:** Hay 10 pines en el módulo ESP32 sensibles a cambios de capacitancia. Puedes conectar estos pines a ciertas almohadillas del PCB y usarlos como interruptores táctiles.  
- **SPI:** Hay dos interfaces SPI en el módulo, que pueden usarse para conectar pantallas, módulos de memoria SD/microSD y memoria flash externa.  
- **I2C:** Los pines SDA y SCL se usan para comunicación I2C.  
- **Comunicación serial (UART):** Hay dos interfaces UART en este módulo, que pueden transferir hasta 5Mbps de información entre dos dispositivos. UART0 también tiene funciones de control CTS y RTS.  
- **PWM:** Casi todos los pines de entrada/salida del ESP32 pueden usarse para PWM (modulación por ancho de pulso). Usando estos pines se pueden controlar motores, luces LED y colores.

## 1.7 Placa Integrada ESP32

![](media/A25.png)

Esta placa de expansión es compatible con la placa de desarrollo Keyestudio Nano Plus y la placa de desarrollo Keyestudio ESP32. El voltaje en VCC puede configurarse a 3.3V (ESP32) o 5V (Nano) mediante un interruptor DIP.

Integra cuatro botones, cuatro LEDs (rojo, amarillo, verde y azul), seis LEDs RGB WS2812, un zumbador, un sensor de movimiento PIR, un receptor IR, un sensor de sonido, una fotorresistencia, un amplificador 8002, un potenciómetro, un sensor ultrasónico, un display de tubo digital de 4 bits, una matriz de puntos 8x8 y un display LCD 1602.

Además, cada pin posee su propio VCC y GND, lo que aporta una mayor compatibilidad a la placa y ofrece más oportunidades para el aprendizaje extendido de otros módulos.
