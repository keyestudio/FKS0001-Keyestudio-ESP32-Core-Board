# 2. Installation du produit

Étape 1 : Retirez le film protecteur de la plaque acrylique.

Étape 2 : Collez les quatre tampons en caoutchouc dans le cercle de positionnement sous la plaque acrylique.

![](media/A1.png)

Étape 3 : Poussez les vis une par une à travers les trous depuis le dessous de la plaque acrylique (le côté avec les tampons en caoutchouc), puis vissez les piliers en cuivre dessus, comme illustré ci-dessous.

![](media/A2.png)![](media/A3.png)

Étape 4 : Alignez les trous de la carte d’extension avec les piliers en cuivre. Vérifiez si les deux trous du milieu sont alignés. Sinon, faites pivoter la carte de 180°. Après ajustement, serrez la carte avec les vis en place.

![](media/A4.png)![](media/A5.png)

Étape 5 : Installez les capuchons des boutons et les capuchons du potentiomètre.

![](media/A6.png)

Étape 6 : Installez la carte ESP32.

Attention :

1. Le port USB de la carte doit être orienté vers l’extérieur. L’installer dans le sens inverse peut endommager la carte.

2. La carte ESP32 doit être complètement insérée dans le port ESP32 de la carte intégrée pour assurer une connexion stable entre la carte interface ESP32 et la carte intégrée, sinon le kit pourrait ne pas fonctionner correctement.

![](media/A7.jpg)

3. Ce kit consomme plus d’énergie lorsqu’il pilote le servo et se connecte au WiFi. Veuillez fournir une alimentation externe pour ce kit.

![](media/A8.png)
